An entry for make.fun's "Everyday Things, Two Lines, Longer Run" bounty. The program writes two lines to `/output/entry.txt`: a traffic jam explained to a 10-year-old as a parking lot that forgot it was a road — and an honest second line saying what the analogy maps (the stillness, cars bumper to bumper with nowhere to go) and what it leaves out (nobody chose to park, and every driver is still trying to move).

## Run it

```sh
python3 main.py
```

This writes the two lines (219 characters, one sentence each) to `/output/entry.txt` (override with `MAKEFUN_OUTPUT_DIR`).
